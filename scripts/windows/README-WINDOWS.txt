MCP Manager for Windows

Double-click start-mcp-manager.cmd for local use.
On first run it creates config.json bound to 127.0.0.1:8080, enables the Admin UI, creates a random Admin token, starts MCP Manager, and opens http://127.0.0.1:8080/admin/.

For advanced/server use, run mcp-manager.exe from PowerShell with explicit commands and configuration.
