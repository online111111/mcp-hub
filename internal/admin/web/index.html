stdio 启动设置

Hub 会作为子进程启动这个 MCP 服务。

参数逐项编辑，保留空项、空格和换行；不需要额外加引号。
环境变量Secret 已设置时不会回显，留空即可保留原值。

远程 HTTP 设置

Hub 会作为 MCP Client 连接远端 Streamable HTTP 服务。

请求 HeadersAuthorization 等敏感值已设置时不会回显。
